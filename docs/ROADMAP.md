# NoUs Roadmap

## 目的

公開学術データ（OpenAlex 等）を用いて、人類の研究を自律的に分析・批評・計算し、
一見無関係な学問領域の「ドッキング」を試みて新しい発見を提案する汎用の仮説発見エンジン。
人類の知の「不可知域」を「全地域」へと変えていく。

## 次の候補

4. **自律ループの拡張**（基本形は実装済み）：討論（`debate`）を使う版、複数ペア並列、探索の多様性指標（同じ概念への偏りの監視）。
5. **理論的飛躍の予測**：分野トレンド（成長・加速）と分野ペア共起の時系列から、
   「今後急接近しそうな分野ペア」を予測し、その接点で仮説を生成する。過去データでの後ろ向き検証を行う。
6. **棄却後の再生成**：自律ループで棄却された理由（既出の最近傍論文）を次の生成プロンプトに渡して作り直す。
7. **模擬宇宙ビュー**：分野を星系、架橋論文を航路、Void を未踏宙域として描く俯瞰 UI（`interface/`）。
