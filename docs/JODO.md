# 浄土（Jōdo）— NoUs の記憶

NoUs が見たものを、仮説が通ったかどうかに関係なく残す場所。Obsidian の vault（Markdown ファイルの集まり）として、データベースから書き出す。

> 設定の出典: 浮黎（記憶の星神）の「浄土」「善見天」、メモキーパー、焼却人。NoUs（知恵）が剪定したものも、ここには残す。

## 名前

| 名前 | 実体 |
|---|---|
| 浄土 | Obsidian の vault（`Drive/AI/projects/浄土`） |
| 善見天 | vault の中心（目次と、人が昇格させた仮説） |
| 記憶域 | SQLite（`data/nous.db`）。**正本** |
| 憶質 | ChromaDB。意味の索引 |
| メモキーパー | 収集。OpenAlex などから、判断せずに書き込む |
| 焼却人 | 選別。層を決めて理由を残す（**削除も書き換えもしない**） |

名前は変更できる（`nous/vault.py` の `NAMES`、フォルダ名の定数）。

## 層（焼却人の分類）

| 層 | フォルダ | 条件 |
|---|---|---|
| 善見天 | `善見天/` | 人が `nous.py vault --promote hyp:N` で昇格（取り消した仮説は除く） |
| 浄土 | `仮説/` | 自律ループが採用（候補）、または未判定 |
| 灰 | `灰/` | 自律ループが棄却、または `retract` で取り消し。**理由つきで保存** |

「採用」は「これらのチェックでは既存文献に見つからなかった」の意味で、新発見の主張ではない。

## 書き出されるもの（最初の範囲）

- `仮説/` `灰/` `善見天/` の `hyp-N.md`: 本文、分類と理由、自律ループの結果、既知研究チェック（理由と根拠の論文）、概念の組合せ、最も近い既存研究、生成の材料にした論文、評価
- `論文/W….md`: 仮説に触れた論文（最も近い既存研究・橋渡し・概念の共起）と、どの仮説が参照したか
- `分野ペア/`、`実行履歴.md`、`討論の仮説/`（`scepter-N.md`）
- `善見天/目次.md`: 目次（層ごとの件数と一覧）

OpenAlex の全件は入れない（触れた論文だけ）。ノートはすべて id 名（`hyp-31.md`、`W2741809807.md`）で、題名は本文と `aliases` にある。

## 守ること

1. **SQLite が正本**。vault は再生成できる書き出しで、同期は一方向（DB → vault）。
2. 書き出しは、内容が変わったノートだけを書く（Drive の同期を増やさない）。前回の書き出しが作ったノートだけを、不要になれば消す。**それ以外（`人のメモ/`、`.obsidian/` など）は触らない**。
3. 前回よりずっと小さい書き出し（空のデータベースなど）では、何も消さない（`--force` で消す）。
4. 捏造をこの vault に混ぜない（将来の「神秘」の出力は、別の場所に、合成のタグを付ける）。

## 使い方

Colab のフォーム（`nous_colab.ipynb`）では、やること「浄土へ書き出す」を選んで ▶ を押すだけです（実行ログは `浄土/実行ログ/` に残り、書き出しの対象外なので上書きされません）。コマンドで行う場合:

```
save()                       # 先に DB を Drive へ保存
!python nous.py vault        # 浄土へ書き出す（既定: Drive/AI/projects/浄土）
!python nous.py vault --promote hyp:31 "あとで読む"    # 昇格（次の書き出しで 善見天/ へ移る）
```

## Drive と Obsidian の同期

1. PC に **Google Drive for desktop** を入れ、`マイドライブ/AI/projects/浄土` が PC から見えるようにする。
2. ストリーミング設定の場合は、`浄土` フォルダを右クリックして「オフラインで使用可能」にする（表示名は版により異なる）。ミラーリング設定ならそのままでよい。
3. Obsidian で「フォルダを保管庫として開く」から、その `浄土` フォルダを選ぶ。
4. **書き込み先を分ける**: `浄土` のノートを書き換えるのは Colab の `vault` だけ。PC では `人のメモ/` にだけ書く（同じファイルを両方が書くと、Drive が競合コピーを作る）。
5. Colab で書き出したあと、Drive の同期が済むまで少し待つ。
