# NoUs Roadmap

## 目的

公開学術データ（OpenAlex 等）を用いて、人類の研究を自律的に分析・批評・計算し、
一見無関係な学問領域の「ドッキング」を試みて新しい発見を提案する汎用の仮説発見エンジン。
人類の知の「不可知域」を「全地域」へと変えていく。

## 完了

| フェーズ | 内容 |
|---|---|
| 0 | Drive 版の取り込み・既存バグ修正 |
| 1 | 評価：ルーブリック LLM 審査（5視点）・人間評価・埋め込み新規性・ICC |
| 2 | 構造抽象化：分野語を排した構造記述 + モチーフ語彙による structural_sim |
| 3 | OpenAlex：26分野の収集・分野共起 lift による Void Zone・分野トレンド |
| 3.5 | 評価の改善：JSON 再試行・LLM/人間の一致度分離・別モデル審査員・OpenAlex 文献チェック（6 の前倒し）・分野名統一 |

## 次の候補

4. **自律ループ**：`voids → fillvoids → abstract → debate(Void ペア) → evaluate` を定期実行し、
   高評価の仮説だけを知識ベースへ還流（`sync`）。評価スコアを報酬として探索先を選ぶ。
5. **理論的飛躍の予測**：分野トレンド（成長・加速）と分野ペア共起の時系列から、
   「今後急接近しそうな分野ペア」を予測し、その接点で仮説を生成する。過去データでの後ろ向き検証を行う。
6. **文献による反証チェック**：`litcheck` で最近傍の既存論文と lit-novelty を記録済み。今後は「既出」と判定された仮説を自律ループで棄却・再生成する。
7. **模擬宇宙ビュー**：分野を星系、架橋論文を航路、Void を未踏宙域として描く俯瞰 UI（`interface/`）。
